# Suffice submission checklist

**Competition:** [Gemma 4 Developer Agent Paper Track](https://www.kaggle.com/competitions/gemma-4-developer-agent-paper/overview)

**Rules checked:** November 12, 2026. The official overview and complete live [Rules page](https://www.kaggle.com/competitions/gemma-4-developer-agent-paper/rules) were reviewed. The stated deadline is **November 12, 2026 at 23:59 UTC**, or **5:59 PM CST in Chicago**. Recheck the live page before submitting.

Checked boxes describe completed artifact preparation. Unchecked boxes require entrant/account facts or actions that were not performed. This checklist does not certify entrant eligibility, accept legal terms, or represent a submitted entry.

## 1 Manuscript requirements

- [x] Title and subtitle are explicit and match the prepared entry fields.
- [x] Abstract, introduction, research methods and experiments, related work, and citations are included.
- [x] The entire manuscript is below the **3,000-word maximum**. Title, subtitle, references, tables, captions, and mathematical text are included conservatively; final counts and methods are in `support/PAPER_VERIFICATION.json`. No minimum, fixed page count or mandatory paper template was identified.
- [x] PDF and editable Word versions contain the same substantive manuscript as the Markdown Writeup.
- [x] Main results use the frozen 0.13 experiment; numerical gains from different releases are not compounded.
- [x] The empty control, timing boundary, paired estimator, order effects, influential observations, and limits of generalization are reported.
- [x] The new read bridge is explicitly separate from the frozen transport timing. No Gemma inference, token savings, task-success gains, Windows execution or whole-process memory bounds are invented.
- [x] Related work credits established caching, generation and transport mechanisms. Claims of novelty concern the scoped executable resource and evidence.
- [x] AI assistance is disclosed. Internal AI-assisted checks are not described as external peer review.
- [x] The final PDF has been rendered and inspected page by page; tables, figure, equations and references are legible. See the recorded verification result.

## 2 Evidence and companion files

- [x] The exact-output study records 100 native processes, 4,840 checks, 23,480 rows and 419,571,140 repeated body bytes.
- [x] The bridge's separate final gate records four native processes, 114 checks, twelve complete observations, six byte-identical transport comparisons and 36 expected rejections.
- [x] All five notebook code cells execute in order using the supplied standard-library driver. Its receipt distinguishes retained-evidence auditing from fresh native execution or historical timing reproduction.
- [x] The notebook embeds its evidence and needs no model, network download or external compiler for its audit.
- [x] Source, original evidence, build/validation receipts, manifest, figure data and references are supplied. Original release archives are unchanged.
- [x] Existing license notices are retained. The runtime corpus is the project's preserved source corpus; the packet does not introduce competition test labels or private competition datasets.
- [ ] Confirm authorship, originality, unpublished status, ownership and all third-party permissions. Preparation and citation checking cannot certify these personal/legal facts.
- [ ] Confirm permission to publish every source, input, attachment and external tool/data dependency. Apply the paper-track rules on external data access, reasonable cost, commercial-use code licensing, reproducibility and competition-data security.

## 3 Entrant and team requirements

- [ ] Confirm the entrant's age/majority or applicable consent exception, permitted residence, sanctions/export eligibility, and any employer authorization under the full rules.
- [ ] Read and accept the applicable rules personally. Confirm ability to comply with conditional winner obligations, including Apache 2.0 licensing, source/document delivery, and applicable tax, privacy and publicity terms. The original MIT notice has not been replaced automatically.

- [ ] If selected as a potential winner, meet the stated one-week response and two-week documentation deadlines, together with the other applicable prize conditions.

## 4 Create the actual entry

- [ ] Join the **paper track** and create its Kaggle Writeup. Participation in the separate prediction competition is not required by the reviewed paper-track overview.
- [ ] Enter the exact title, subtitle and manuscript from the prepared files. Upload `paper/figures/transport_paper.png` through the editor; replace the local image path and inspect the rendered figure.
- [ ] Check the final editor's word count after any author edits. Keep all manuscript content at or below 3,000 words; do not append the working notes or companion reports.
- [ ] If supplying the optional notebook, upload the prepared `.ipynb`, run it in Kaggle, review its outputs, make it public, and add its public URL under Project Links. Private attachments may become public after the deadline; review them first.
- [ ] If supplying the optional PDF, host the final PDF at a genuinely public URL and place it in Public Project Link. Verify access without signing in or paying. A private ChatGPT download link is not evidence of public Kaggle accessibility.
- [ ] Preview the complete Writeup and verify citations, table values, image, PDF/notebook links, attribution and required declarations.
- [ ] **Press Submit before the deadline.** A saved draft is not a valid submission. Verify the submitted status and the intended final selection.

## Judging coverage

| Equally weighted criterion | How the revision addresses it | Remaining substantive limit |
|---|---|---|
| Novelty | One precise observation/completion contract and an inspectable resource; prior mechanisms attributed | No claim to invent caching or binary framing |
| Quality | Matched comparisons, complete outputs, negative control and retained unfavorable observations | One source corpus and one shared Linux configuration |
| Relevance | Concrete, tested host-approved repository read tool and coordinated-edit requirements | No real Gemma episode or issue-resolution evaluation |
| Verifiability | Frozen sources/inputs, executed audit notebook, native receipts and per-file hashes | Offline audit cannot recreate historical execution or time |
| Clarity | Focused manuscript, two tables, paired-observation plot, defined metrics and explicit limits | Entrant must still check the final Kaggle editor preview |

The official rubric assigns each criterion 0–5 and averages them equally. This table is a preparation map, not a predicted judge score or an eligibility ruling. The full official rules control; `research/competition_rules_review.md` and its source ledger preserve the scope of the review.
